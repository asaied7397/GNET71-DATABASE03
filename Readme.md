# SQL Server Database Assignment

## Description

Implementation of relational databases using Microsoft SQL Server.

## Databases

### 1. E-Commerce Database

Includes:

- Customers
- Products
- Categories
- Suppliers
- Orders
- Payments
- Shipments
- Reviews

### 2. Hotel Reservation Database

Includes:

- Hotels
- Rooms
- Guests
- Reservations
- Payments
- Services

## Tools

- Microsoft SQL Server 2022
- Docker
- VS Code MSSQL Extension
